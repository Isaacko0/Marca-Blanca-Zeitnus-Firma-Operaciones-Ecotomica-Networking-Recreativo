## Resumen Ejecutivo

Documento fundacional que **redefine la relación OVN-HSCSG**: OVN como **capa operativa de organización productiva** dentro de HSCSG, **no como modelo económico rector**.

**Tesis central**: OVN responde "cómo organizar red productiva abierta y reconocer contribuciones"; HSCSG responde "cómo conseguir que esa red produzca autonomía, reciprocidad, regeneración y continuidad para todos".

## 1. Arquitectura OVN (Extracción Operativa)

### 4 Niveles OVN
| Nivel | Enfoque |
|-------|---------|
| **Global** | Interoperabilidad: estándares compartidos, constitución global, custodios, coordinación entre redes |
| **Red** | Bienes comunes: infraestructura, reputación, marca colectiva, solidaridad, reglas, servicios compartidos |
| **Empresa Abierta** | Coordinación interproyectos: marcas, responsabilidades legales, contratos, servicios, producción, comercialización |
| **Proyecto** | Ejecución: tareas, roles, recursos, contribuciones, decisiones, verificación, resultados |

### 3 Procesos Económicos OVN
| Proceso | Función |
|---------|---------|
| **Creación de valor** | Producir bienes, servicios, conocimientos, recursos |
| **Captura de valor** | Identificar valor convertible en ingresos/recursos económicos |
| **Distribución de valor** | Reconocer contribuciones y distribuir ingresos |

### Ciclo Operativo OVN (7 pasos)
1. Iniciación → 2. Acuerdo (reglas valoración/gobernanza/conflictos) → 3. Registro (contribuciones) → 4. Referenciación (uso contribuciones anteriores) → 5. Equidad fluida (participación económica estimada) → 6. Distribución (ingresos según acuerdos) → 7. Cocreación e intercambio

### Clasificación de Contribuciones
- **Proyecto**: materiales, trabajo, recursos dedicados a iniciativa
- **Red**: herramientas, espacios, infraestructura compartida entre proyectos
- **Bienes comunes**: conocimiento, estándares, recursos aprovechables entre redes

### 10 Subsistemas Infraestructura OVN
Conexión, Información, Coordinación, Cocreación, Contabilidad, Evaluación, Gobernanza interna, Intercambio, Gobernanza externa, Interoperabilidad

### 3 Sistemas Sensorica (Investigación Posterior)
Contabilidad de contribuciones + Reputación + Roles + Planificación recursos red (NRP)

## 2. Correspondencia Estructural OVN → HSCSG

| OVN | HSCSG | Relación |
|-----|-------|----------|
| Gobernanza proyectos/redes | **CDS** | Decisión distribuida, revisión acuerdos |
| Código abierto/diseños compartidos | **OAD** | Conocimiento reutilizable, fabricación local |
| Contribution Accounting System | **ITC** | Registro aportaciones, procedencia valor |
| Roles, tareas, planificación recursos | **COS** | Coordinación operativa, asignación capacidades |
| Evaluación, reputación, aprendizaje | **FRS** | Retroalimentación, corrección, aprendizaje colectivo |
| Bienes comunes de red | **Cosatecas + Comunes HSCSG** | Infraestructura compartida, acceso colectivo |

### Diferencia de Propósito
| Dimensión | OVN | HSCSG |
|-----------|-----|-------|
| Unidad organizativa | Proyecto, empresa abierta | Comunidad, ecosistema, sistema de vida |
| Objeto coordinación | Contribuciones, producción | Recursos, necesidades, capacidades, continuidad |
| Resultado económico | Ingresos redistribuidos | **Autonomía material, acceso universal progresivo** |
| Conocimiento | Bien común productivo | **Bien común transgeneracional** |
| Infraestructura | Soporte colaboración | **Soporte autonomía y regeneración** |
| Automatización | Eficiencia, producción distribuida | **Destrabajo, recuperación tiempo humano** |
| Reputación | Confianza, asignación roles | **Memoria reciprocidad sin jerarquía moral** |
| Sostenibilidad | Viabilidad financiera/social/ambiental | **Continuidad ecológica, metabólica, civilizatoria** |

## 3. Integración: Qué Integrar / Adaptar / No Importar

### A. Integración Directa (Casi Directa)
1. **Registro trazable de contribuciones** → ITC (memoria operativa, no deuda monetaria)
2. **Referenciación conocimientos** → OAD + memoria transgeneracional
3. **Tareas, roles, responsabilidades** → COS (tarea vs rol, custodia temporal)
4. **Modularización/fabricación distribuida** → OAD + autonomía productiva (Xtreme Manufacturing)
5. **Bienes comunes** → Cosatecas (clasificación proyecto/red/comunes)
6. **Solidaridad ante fallos** → distinguir negligencia vs incertidumbre vs aprendizaje

### B. Integración Condicionada (Adaptación Profunda)
1. **Fluid equity** → **Separar 4 registros**: Contribución, Responsabilidad, Uso recursos, Beneficios económicos. No determinar dignidad/derecho a existir.
2. **Reputación** → función limitada: informar experiencias/competencias/confiabilidad contextual. NO puntuación global valor humano.
3. **Democracia líquida** → revocable, transparente, limitada alcance. Derechos fundamentales NO dependen de popularidad.
4. **Custodios** → función fiduciaria, temporal, auditable. Custodiar ≠ poseer.
5. **Empresas abiertas** → unidades ejecución transición, subordinadas a autonomía/regeneración.

### C. No Integrar (Principios Rectores a Evitar)
1. **Mercado como destino universal** → mercados como instrumentos transición, no todo valor = transacción
2. **Equivalencia contribución = ingreso** → trabajo no remunerado, cuidado, recuperación ecológica no se valoran en precios mercado
3. **Reputación como exclusión** → NO licencia para acceso alimentación, agua, vivienda, salud, conocimiento, herramientas esenciales
4. **Marca como legitimidad** → confianza en resultados verificables, transparencia, continuidad, ética (no solo identidad comercial)

## 4. Arquitectura Integrada Propuesta (5 Capas)

```
Capa 1 — Propósito y límites civilizatorios (HSCSG: autonomía, reciprocidad, destrabajo, continuidad ecológica)
Capa 2 — Gobernanza y conocimiento (CDS + OAD + FRS)
Capa 3 — Operación productiva (COS + ITC + mecanismos OVN adaptados)
Capa 4 — Infraestructura metabólica (Cosatecas + AgriHoods + fab labs + energía + agua + vivienda + reparación)
Capa 5 — Intercambio y transición económica (Mercados, servicios, crédito mutuo, ahorro-inversión-tanda, monetarios transitorios)
```

**Funcionamiento**: Circuito de retroalimentación (no cadena de mando). Necesidades → decisiones → proyectos → infraestructura/conocimiento → autonomía → tiempo/capacidades liberadas → nuevos proyectos.

### Ejemplo: Red Local Autonomía Hídrica
| Función | Implementación HSCSG+OVN |
|---------|--------------------------|
| Necesidad | COS integra demanda, disponibilidad, prioridades |
| Diseño | OAD publica planos, especificaciones, protocolos |
| Decisión | CDS define ubicación, reglas acceso, responsabilidades |
| Participación | ITC registra diseño, materiales, instalación, mantenimiento, aprendizaje |
| Producción | Fab labs/talleres locales fabrican componentes |
| Infraestructura | Cosateca facilita herramientas compartidas |
| Evaluación | FRS analiza calidad agua, fallos, consumo, continuidad |
| Custodia | Responsables temporales protegen instalaciones/equipos |
| Intercambio | Excedentes comerciales financian mejoras, **sin condicionar derecho al agua** |

**Indicador principal HSCSG**: cuánto aumentó autonomía hídrica, cuánta agua sostenible, cuánto tiempo trabajo liberado, resiliencia sistema. Ingresos = variable secundaria.

## 5. Mecanismo Faltante: Contabilidad Metabólica (RMR)

> **ITC** = ¿Quién contribuyó, qué aportó, qué conocimiento produjo?
> **RMR (Registro Metabólico de Recursos)** = ¿Qué recursos entraron, transformaron, consumieron, recuperaron, regeneraron?

### RMR Debe Registrar
- Agua: captada, almacenada, utilizada, tratada, devuelta
- Energía: generada, consumida, almacenada, perdida
- Biomasa: producida, consumida, compostada, regenerada
- Nutrientes: recuperados, reincorporados al suelo
- Materiales: extraídos, reutilizados, reparados, descartados
- Capacidad productiva disponible, demanda estimada
- Tiempo trabajo humano requerido, tiempo liberado por automatización
- Capacidad mantenimiento, continuidad sistemas

### Indicadores Autonomía (vs Rentabilidad)
1. **Autonomía**: proporción necesidades satisfechas con capacidades/infraestructura propias
2. **Regeneración**: balance recursos/procesos ecológicos
3. **Resiliencia**: capacidad continuar ante interrupciones
4. **Destrabajo**: tiempo humano liberado sin transferir costes
5. **Accesibilidad**: distribución efectiva beneficios
6. **Reparabilidad**: capacidad local mantener/recuperar infraestructura
7. **Continuidad transgeneracional**: conocimiento, recursos, capacidades para siguientes generaciones

## 6. Vacíos Persistentes (Ambos Modelos)

| Vacío | OVN | HSCSG (Desarrollo Pendiente) |
|-------|-----|------------------------------|
| **Acceso universal** | Redistribuye ingresos según contribuciones | **Derechos acceso independientes de productividad individual** |
| **Contabilidad ecológica** | Estándares ambientales, no metabólica completa | **RMR, balances biofísicos, límites regeneración** |
| **Asignación recursos escasos** | Planificación/gobernanza | **Reglas explícitas prioridad: necesidad, disponibilidad, impacto ecológico** |
| **Cuidados/reproducción social** | Contribuciones amplias, no economía cuidado | **Registrar/sostener cuidados, mantenimiento, trabajo reproductivo** |
| **Automatización** | Eficiencia, fabricación | **Garantizar liberación tiempo, no concentración control** |
| **Conflictos valoración** | Ecuaciones valor, evaluaciones participativas | **Evitar fórmula determine valor humano/derecho recursos** |
| **Poder y captura** | Custodios, gobernanza | **Controles contra concentración infraestructura, datos, algoritmos, decisiones** |
| **Continuidad** | Reputación, solidaridad, estabilidad red | **Protocolos sucesión, resiliencia, reparación, memoria transgeneracional** |
| **Escalabilidad** | Arquitectura teórica, experiencias redes | **Validación empírica comunidades, regiones, sistemas materiales** |
| **Transición económica** | Intercambio mercantil = ingresos | **Definir paso de monetario a acceso material menos dependiente dinero** |

### Vacíos Críticos Detallados
1. **Acceso ≠ Contribución** — persona sin contribuir (edad, discapacidad, enfermedad, cuidados) NO pierde acceso bienes comunes
2. **Teoría operativa escasez material** — modelar flujos físicos, límites ecológicos (qué producir, importar, regenerar, NO extraer)
3. **Economía del cuidado** — cuidado infantil, mayores, alimentación, mantenimiento, acompañamiento, educación, transmisión cultural = **infraestructura continuidad**
4. **Reputación ≠ jerarquía** — separar competencia técnica, cumplimiento compromisos, experiencia contextual, poder decisión, derecho acceso
5. **Continuidad transgeneracional operativa** — diseños, inventarios, historial mantenimiento, sucesión, reparación, memoria ecológica, conocimiento ancestral, protocolos recuperación

## 7. Secuencia Implementación Propuesta

| Fase | Enfoque | Entregable |
|------|---------|------------|
| **1. Protocolo Contribuciones** | Adaptar registro/referenciación OVN a ITC | Aportaciones humanas, materiales, intelectuales, infraestructura → sin créditos económicos automáticos |
| **2. Gobernanza y Coordinación** | Integrar tareas, roles, custodia, verificación, mediación, bifurcación en CDS/COS | Límites autoridad, mecanismos revocación |
| **3. Bienes Comunes Productivos** | Conectar OAD con Cosatecas, herramientas, fab labs, producción local | Licencias, mantenimiento, inventarios, reglas acceso |
| **4. Contabilidad Metabólica** | Desarrollar RMR + vincular FRS | Flujos materiales, regeneración, necesidades, capacidad productiva, desperdicios, tiempo liberado |
| **5. Economía Transición** | Intercambio, servicios, ahorro-inversión-tanda, financiación infraestructura | Acceso bienes esenciales separado de productividad individual |

### Piloto Validación: Cosateca Comunitaria
**Inventario real herramientas + necesidades** → demostrar:
- Registro aportaciones/recursos
- Acceso verificable herramientas compartidas
- Mantenimiento infraestructura
- Diseños/conocimientos abiertos
- Decisiones revisables
- Disminuye compra herramientas infrautilizadas
- Aumenta autonomía material participantes

**Métrica principal**: trabajo, gasto, dependencia, desperdicio evitado (sin trasladar costes a personas/ecosistema)

## 9. Conclusión Estratégica + Hipótesis Síntesis

### 3 Ideas OVN Valiosas para HSCSG
1. **Trazabilidad contribuciones** — ninguna aportación relevante desaparece memoria colectiva
2. **Gobernanza multinivel** — proyectos, redes, bienes comunes = reglas diferenciadas
3. **Infraestructura colaboración** — cooperación no depende solo voluntad individual, sino sistemas encontrar/compartir/producir/mantener/aprender

### 4ta Idea HSCSG (que OVN no resuelve)
> **Transición desde distribución ingresos → autonomía material y acceso universal**

### Principio Rector Propuesto
> "La contribución debe ser visible, pero la dignidad no debe depender de ella. Los recursos deben administrarse, pero su administración no debe convertirse en propiedad sobre quienes los necesitan. La producción debe generar valor, pero su éxito debe medirse por la autonomía y la continuidad que proporciona, no exclusivamente por los ingresos que consigue distribuir."

### Hipótesis Síntesis (Conceptual)
```
Autonomía colectiva = (Conocimiento abierto × Infraestructura compartida × Regeneración) / (Dependencia externa + Fricción metabólica)
```

### Orden de Integración
> **Integrar OVN DENTRO de HSCSG** (como motor organización productiva), NO HSCSG dentro de OVN.
> Evita que arquitectura para distribuir valor económico defina límites de propuesta cuyo objetivo es superar esa dependencia.
