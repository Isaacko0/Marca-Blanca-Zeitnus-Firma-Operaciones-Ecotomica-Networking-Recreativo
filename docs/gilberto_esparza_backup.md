## 2. OBRAS CLAVE — EJECUCIÓN REAL DOCUMENTADA

### 2.1 PLANTAS NÓMADAS (2008-2014) — EL ANTECEDENTE DIRECTO

| Aspecto | Detalle Técnico |
|---------|-----------------|
| **Concepto** | Robot autónomo que **busca agua contaminada**, la procesa con **células de combustible microbianas (MFC)**, genera electricidad para moverse, y **libera agua limpia** |
| **Metabolismo** | Bacterias anaerobias (Geobacter, Shewanella) oxidan materia orgánica → electrones → corriente eléctrica |
| **Autonomía** | Navega por GPS + sensores, busca "comida" (aguas residuales), evita obstáculos |
| **Despliegues reales** | Río Lerma (México), Río Santiago (Jalisco), Canal Nacional (CDMX), Bienal de Venecia 2012 |
| **Resultados medidos** | Reducción DBO/DQO en agua tratada, voltaje generado (0.3-0.6V por celda), autonomía días-semanas |
| **Hardware** | Chasis impreso 3D, motores DC, Arduino/Raspberry Pi, sensores pH/ORP/temperatura, MFCs caseras (grafito + membrana) |
| **Ciclo de vida** | Robot "muere" cuando MFCs se agotan → se recupera → se re-inocula → renace |

> **Cita Esparza:** *"Plantas Nómadas no es una metáfora. Es un organismo artificial que come contaminación y excreta energía. Si se le acaba la comida, muere. Así de simple."*

### 2.2 AUTOFOTOSÍNTESIS (2013-2017) — SISTEMA ALGAL-ROBÓTICO

| Componente | Especificación |
|------------|----------------|
| **Biorreactor** | Tubos de policarbonato 200L + *Chlorella vulgaris* + *Scenedesmus* |
| **Robot** | Plataforma móvil que agita, circula, mide pH/OD/temperatura, cosecha biomasa |
| **Producto** | Biomasa algal (proteína, lípidos) + O₂ + biomasa residual → biogás |
| **Integración** | CO₂ de combustión → algas → O₂ para combustión (ciclo cerrado) |
| **Despliegue** | Instalación en Ex Teresa Arte Actual (CDMX), funcionamiento continuo 6 meses |
| **Métricas** | 15g biomasa/m²/día, 80% remoción N/P, 200W/m² productividad fotosintética |

### 2.3 BIOSONOT / PLANTAS AUTÓNOMAS (2015-2020) — SONIDO COMO MÉTRICA VIVA

- **BioSoNot**: Micrófonos hidrófonos en biorreactores → sonido = metabolismo bacteriano en tiempo real
- **Plantas Autónomas**: Versión simplificada de Plantas Nómadas para talleres comunitarios
- **Output**: Archivos de sonido (data sonification) + data logs CSV + hardware abierto

## 8. RIESGOS Y MITIGACIONES (ESTILO ESPARZA)

| Riesgo | Probabilidad | Impacto | Mitigación (Estilo Esparza) |
|--------|--------------|---------|----------------------------|
| **MFC no genera voltaje** | Alta | Crítico | 3 MFCs en paralelo + inóculo múltiple (río + lodo + compost) |
| **Bacterias mueren** | Media | Alto | Reserva inóculo en nevera + re-inoculación semanal + "banco genético" lodo |
| **Robot se traba/rompe** | Media | Medio | Chasis modular (tornillos, no pegamento) + repuestos impresos 3D |
| **Spirulina se contamina** | Media | Medio | Medio axénico simple (cloro 1ppm + filtro 0.22μm) + reserva cepa pura |
| **Sensor falla** | Baja | Medio | Triplicar sensores críticos (voltaje, pH) + voting |
| **Comunidad no colabora** | Baja | Alto | Iniciar CON comunidad (no para ellos) → talleres "Plantas Autónomas" |
| **Permisos/legalidad** | Media | Medio | Colaborar con autoridad agua local + universidad (aval académico) |
