**Stack**: TypeScript + React + @remotion packages

## Descripción original
Creación de videos programáticamente con React. Remotion permite componer videos usando componentes React, animaciones basadas en frames, y rendering server-side.

## Paquetes clave
- `@remotion/player` — reproductor de video
- `@remotion/player-components` — controles UI
- `@media/` — decodificación/encapsulado de medios
- `@remotion/tailwind` — integración con Tailwind
- `@remotion/lambda` — rendering serverless
- `@remotion/three` — integración Three.js

## Funcionalidades principales
1. Composición de video con React components
2. Animación basada en frames (useCurrentFrame, useVideoConfig)
3. Timeline/secuencias con `<Sequence>`
4. Audio/SFX/Speech con `@remotion/sfx`, `@remotion/speech`
5. Captions automáticas
6. Server-side rendering (Lambda, Vercel)
7. Editor visual (Editor Starter)
8. Mediabunny para procesamiento de medios
