## 2. NEOCAMERALISMO: ANÁLISIS RIGUROSO (Sin Adherencia Ideológica)

### 2.1 Definición Técnica (Extraída de Fuentes Primarias)

> **Neocameralismo** (Curtis Yarvin / Mencius Moldbug, 2007-2008):  
> *Reimagina el Estado como una corporación de accionistas (SovCorp) gobernada por un CEO con poder absoluto, supervisado por un directorio secreto que puede removerlo. Múltiples SovCorps compiten en un **Patchwork** — mosaico de jurisdicciones soberanas pequeñas donde los residentes "votan con los pies" (exit).*

### 2.2 Componentes Estructurales (Despojados de Carga Ideológica)

| Componente | Definición Formal | Isomorfismo HSCSG/ALRAC |
|------------|-------------------|-------------------------|
| **SovCorp** | Entidad soberana corporativa: monopolio violencia + residual claimant | **Nodo ALRAC** = soberanía operativa + residual claimant = comunidad (no accionistas) |
| **CEO/Directorio** | Gobernanza jerárquica: CEO ejecuta, directorio remueve (accountability) | **CDS + CEL** = gobernanza distribuida: asamblea 1a1v + jurados sorteados (accountability distribuida) |
| **Patchwork** | Sistema de múltiples SovCorps compitiendo por residentes/capital | **Federación ALRAC** = nodos federados compitiendo por coherencia/encaje (no por extracción) |
| **Exit** | Mecanismo correctivo principal: salida individual → competencia | **Exit distribuido** = γ-CARMIS reconfiguración coordinada (no salida individual, reconfiguración colectiva) |
| **Voice vs Exit** | Hirschman invertido: Exit primario, Voice residual (directorio) | **Voice primario** (asambleas/CEL), **Exit como último recurso** (federación permite fork suave) |
| **Legitimidad** | Competencia → calidad de vida → legitimidad *de facto* | **Legitimidad** = encaje (𝕮-Atlas) + armonía (αʰ) + evidencia (RAO) |

### 2.3 Diferencias Fundamentales (No Reconciliables)

| Eje | Neocameralismo | HSCSG/ALRAC | Veredicto |
|-----|----------------|-------------|-----------|
| **Soberano** | Accionistas (capital) | Comunidad (personas 1a1v) | **INCOMPATIBLE** |
| **Gobernanza** | Jerárquica CEO+Directorio | Distribuida CDS+CEL+γ-CARMIS | **INCOMPATIBLE** |
| **Mecanismo Correctivo** | Exit individual (competencia) | Reconfiguración colectiva (γ-CARMIS) | **INCOMPATIBLE** |
| **Economía** | Capitalista autoritario | Postmonetario (TQ/ZNU) + CaaS | **INCOMPATIBLE** |
| **Justificación** | "Competencia → eficiencia" | "Encaje → regeneración" | **OPUESTOS** |
