## Hallazgos Clave para Zeitnus (vs Modelo Económico OVN Wiki)

### 1. Value Equation Development (Sección V) — **Detalle Faltante en Wiki**
El paper original tiene sección dedicada a **"Development of value equation"** — el mecanismo matemático/algorítmico para redistribución de beneficios. En el wiki solo se menciona "Benefit redistribution algorithm" sin detalle.

### 2. 4-Level Structure Detallada — **Más Específica que Wiki**
- **Project Level**: Collaboration model detallado
- **Open-enterprise Level**: Estructura inter-project (ventures, exchange firms)
- **Network Level**: Network commons + Network governance (explícito)
- **Global Level**: Global governance + Legal framework

### 3. Infrastructure & Best Practices (Sección VII) — **Capa Operativa**
- Physical/Virtual Infrastructure
- Communication & coordination mechanism (estigmergia operativa)
- **Value creation, accounting and evaluation mechanism** — NRP-CAS precursor
- Exchange and governance mechanisms
- **Xtreme Manufacturing (XM)** — Wikispeed case: agile manufacturing, modular architecture
- Conflict management practices

### 4. Legal Framework (Global Level) — **Explícito**
- Legal framework como componente de Global Level Structure

### 5. Examples: Open Value Gardening Network
- Segundo ejemplo OVN além de Sensorica — agricultura/horticultura
