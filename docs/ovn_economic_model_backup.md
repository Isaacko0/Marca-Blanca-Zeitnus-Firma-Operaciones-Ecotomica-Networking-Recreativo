## Resumen Ejecutivo

El modelo económico OVN implementa **principios de economía p2p** (colaborativa/participativa) — una rama de la **economía de la complejidad**. Encarna nuevas relaciones, procesos y mecanismos de coordinación para: obtención de recursos, innovación, producción, difusión y captación de beneficios, realizadas por **agentes libres que participan voluntariamente en procesos sin permiso**.

**Modo de producción**: **Producción entre pares basada en bienes comunes (CBPP)**. Para CBPP genuina, la infraestructura debe estar bajo **régimen de propiedad no dominante (non-dominium)** — inapropiable por cualquier entidad, incluidos Estados.

**Interpretación**: Economía p2p = expresión institucional de economía de la complejidad (ecologías adaptativas de agentes interactuando). OVN = **instituciones de procesamiento de complejidad**, no solo "organizaciones alternativas".

## 1. Principales Inquilinos Teóricos

### Patrones Arquitectónicos Pre-figurativos (Bitcoin como ejemplo)
| Principio | Descripción |
|-----------|-------------|
| **Propiedad** | Infraestructura = non-dominium (no pertenece a nadie, acceso sin permiso, reglas inmutables en protocolo) |
| **Transparencia** | Todo accesible: código, métricas, desarrollo, wallets, transacciones |
| **Apertura** | Cualquiera puede unirse: minero (infra física), desarrollador (software), usuario (wallet/transacciones), proveedor servicios L2 |
| **Gobernanza meritocrática** | Quienes sostienen infra física (mineros) tienen última palabra en evolución de la red |
| **Génesis** | Inicio sin VC/financiación pública; mercado no necesario para crecimiento (aunque acelera) |
| **Transnacional** | Escapa marcos regulatorios tradicionales Estados/tratados |

### Fundamento Teórico: Reducción Costos Transacción (Coase → Benkler → Shirky → Feldstein)

**Coase (1937)**: Individuos operan como autónomos si costos transacción suficientemente bajos → no ventaja operar en organización cerrada.

**Benkler (Riqueza de las Redes)**: Reducción requisitos capital para producción información → (1) reduce valor estrategias propietarias, (2) fomenta motivaciones diversas (de principal a una de muchas), (3) permite esfuerzos cooperativos a gran escala imposibles antes.

**Shirky (Suelo Coasiano)**: "Estamos acostumbrados a un mundo donde las pequeñas cosas suceden por amor y las grandes por dinero. Pero ahora podemos hacer grandes cosas por amor." Esfuerzos organizados bajo el suelo coasiano = valiosos pero demasiado costosos para ser asumidos institucionalmente.

**Feldstein**: Cuando costos participación son suficientemente bajos, **cualquier motivación puede ser suficiente para dar lugar a una contribución**. Clave para entender tanto empresas capitalistas como comunidades open source.

### Tibi (Escritos Antiguos)
- Tipo de acuerdo organizativo depende del área de actividad (privadas, públicas, coops, non-profit, **redes abiertas transnacionales globales**)
- Cada modelo prescribe: relaciones/roles, políticas, métodos/procedimientos, infraestructura/herramientas, **mecanismos captura y redistribución objetos de valor**
- Impulsor colaboración: no solo acceso a beneficios, sino **deseo de hacer más, tener mayor impacto**
- Costos participación deben ser bajos (máxima Feldstein), aunque propósito compartido puede superar costos altos
- Beneficios buscados pueden no ser económicos (espirituales, etc.) → **experiencia de valor**

### Benkler: Dos Ventajas Redes Abiertas
1. **Costo oportunidad de la información**: Redes abiertas funcionan mejor en situaciones complejas requiriendo procesar mucha información
2. **Problema asignación de recursos**: Redes abiertas funcionan mejor adaptando habilidades a tareas y asignando recursos a actividad adecuada

### Li & Seering (2019): 5 Mecanismos Comunidad Open Source Reduce Costos/Time-to-Market
1. Feedback pruebas producto → reduce riesgo fallas
2. Desarrolladores comunidad → reducen costos I+D internos
3. Comunidad presenta productos a clientes ideales → reduce marketing/ventas
4. Comunidad = pool talento → ahorra costos reclutamiento
5. Comunidad provee recursos para canales/asociaciones producto-clientes

### Contexto Histórico: Número Dunbar (~150) → Religiiones/Estados/Corporaciones → **Máxima Jerarquía (Bauwens)**: horizontalidad triunfa sobre verticalidad; más competitivo estar distribuido que (des)centralizado. Jerarquías = costos altos (burocracia, falta transparencia/coherencia/rapidez/eficiencia).

## 2. Economía Colaborativa, Participativa y Compartida — Distinciones Semánticas

| Término | Foco | Características Clave |
|---------|------|----------------------|
| **Economía Compartida (Sharing)** | Recursos/activos "compartidos" — acceso no transaccional, mutualizados, redistribuidos, circulados recíprocamente sin ánimo de lucro. Gift (unidireccional) o trueque (bidireccional). Puede ser propiedad o custodia. | Airbnb/Uber = **economía de acceso** (misnomer), no sharing. Críticos: economía de alquiler/microservicios. Uso del activo irrelevante si se preserva integridad y reglas acceso. |
| **Economía Colaborativa** | Asignación tiempo/recursos para **resultado común**. Proceso minimiza intercambios mediados por monedas monetarias. Nadie paga a nadie; nadie monopoliza producción. Ejemplos: Linux, Wikipedia, open source HW/SW. RedHat = consultoría sobre Linux (licencias: sin restricción → no comercial). Contribuciones tangibles (impresora 3D) = contribución no intercambio, no alquiler, uso común proyecto-específico. Redistribución beneficios: reconocimiento público o equidad (promesa beneficios futuros → **Algoritmo Redistribución Beneficios**). |
| **Economía Participativa** | **Proceso** mediante el cual se crea algo colaborativamente. Acceso abierto, barreras entrada muy bajas/nulas (permissionless). Bitcoin = permissionless. Sensorica = permissionless. Coops tradicionales = producción colaborativa PERO acceso participacion condicionado (hiring/invitation). Enspiral/Indias = coops, no redes abiertas. |

**OVN aplica AMBOS**: economía colaborativa + participativa (crowdsourcing, activos en common/non-dominium/shareable pools, acceso sin permiso).

## 3. Propiedad (Régimenes dentro del OVN)

### Aportaciones Materiales y Propiedad Privada
- Afiliados contribuyen recursos propios (espacio, equipos, herramientas, consumibles) a ventures
- Listados en **Shareable Pool** con reglas uso
- Propiedad individual preservada; owners set reglas acceso/uso (sujeto a gobernanza red/riesgo)
- Uso por afiliado → **contribución material registrada** (transacción NRP, PERO no intercambio/rental, no deuda generada)
- Extensible a **propiedad compartida** → contribución atribuida a copropietarios, beneficios divididos por esquema elegido

### Custodia (Non-Dominium) — Forma Principal para Activos Compartidos
- Activos (materiales o inmateriales: marcas, IP) transferidos a **Custodio** (non-profit, trust)
- Custodio = **propietario legal**, protege de captura (confiscación intereses privados), pone a disposición afiliados bajo reglas
- **Custodian Agreement**: obliga gestionar en interés afiliados OVN; promete transferir activos a otra entidad si afiliados insatisfechos, **bajo mismo régimen non-dominium**
- **CAKE** = Custodio de Sensorica

### Activos Digitales → Commons Digitales
- Documentos, diseños, software, imágenes, vídeos → licencias open/Creative Commons
- Bajos costos mantenimiento/administración; costo distribución ≈ 0
- Assets de acciones (stock assets) que no requieren mucha gobernanza

## 4. Recursos

### Elasticidad Radical
- OVN = **organización ilimitada** (apertura = acceso sin permiso participación)
- Transparencia propaga necesidades más allá de la red → atrae nuevos participantes
- No limitada por budget fijo, espacio, capacidad equipamiento, empleados (orgs tradicionales)
- Recursos se expanden dinámicamente según necesidades e incentivos

### Activos Materiales Compartidos → Shareable Pool + Commons + Non-Dominium

### Asignación de Recursos — **Descentralizada**
- Recursos propiedad privada → aportados por afiliados (owners originales) como contribuciones
- Algunos agrupados en **Shareable Pool** (régimen mixto) para armonizar acceso/reglas
- Cada afiliado decide asignación recursos privados (razones individuales/colectivas)
- Otros recursos = commons/non-dominium gestionados en comunidades/ventures/redes mayores

### Presupuesto ≠ Tradicional
- **No hay budget administrado por oficina ejecutiva** en forma p2p pura
- Efectivo necesario → **crowdfunding** → participantes deciden convertir en contribución financiera
- **Acceso empático** (discusión separada)

### Práctica Sensorica
- Grants fiat → **Common Funding Pool** (budget administrado por Custodio)
- Aportaciones afiliados → Custodio ofrece servicios financieros a ventures
- Fondos en cuenta bancaria Custodio → administra según voluntad colectiva afiliados venture (prioridades/planificación públicas)
- Distribución fondos budget compartido → prioridades emergentes/planificación
- Crowdfunding a venture → shared monetary assets administrados por afiliados venture

### DAO Fund Allocation (Comparación)
- Web3 financial primitives + on-chain voting
- Proceso propuesta: plan acción + budget → afiliados votan accept/reject
- Buena administración → quienes ejecutan (con oversight/quality control/audit opcional)

### Mantenimiento Activos Materiales Compartidos (Sensorica)
- Non-dominium ownership → Custodio (trust) garantiza acceso, evita captura
- Reglas acceso → decididas afiliados via gobernanza
- Red decide asignar fondos: mantenimiento, reposición, nuevas adquisiciones
- Actividades realizadas por afiliados
- **Uso remunerado equipos** → % ingresos comerciales extraído y conservado para mantenimiento (materiales + trabajo)
- Custodio **no puede explotar** recursos compartidos para beneficio propio (Custodian Agreement)

## 6. Conocimiento Común

- **Expresión viva de la inteligencia colectiva**
- Innovación requiere conocimiento → procesos innovación redes abiertas dependen inteligencia colectiva
- **Documentación = sustrato** sobre el que desarrolla inteligencia colectiva (herramientas colaboración/coordinación digital)
- Resultado innovación abierta → **abierto en sentido IP** (licencias open source/Creative Commons)
- **Conocimiento NO es recurso** (no se puede identificar/delinear/medir/inventariar/rastrear bien)
- Información, documentos, modelos 3D, código, artículos = **recursos** (artefactos fijos, ubicaciones inequívocas, transferibles)
- **Conocimiento = ser vivo**, no disociable de individuo; puede expresarse colectivamente (inteligencia colectiva); produce información (artefactos)
- Ver: **Stigmergy, Commons, OVN License**

## 7. Moneda

- OVN implementa peer production: contribuciones, riesgo compartido, beneficios proporcionales contribuciones
- **Sistema contabilidad contribuciones** rastrea contribuciones y cómo fusionan en entregable (producto)
- **No hay intercambios en cocreación → no necesidad moneda para procesos internos** (puro peer production)
- Modelos híbridos defendidos por algunos

### Entregable = Producto (Market Distribution)
- Distribuido por **Exchange Firm** (ver sección 15)
- Otros mecanismos: trueque, donaciones
- Recompensas tangibles que regresan al OVN = **Ingresos (Revenue)**
- **Todos los ingresos redistribuidos** entre afiliados según contribuciones pasadas o **fluid equity** (capital fluido), usando sistema contabilidad contribuciones
- Parte → mantenimiento infraestructura (transferida a Custodio)
- Afiliados pueden reinvertir parte ingresos en ventures como contribución financiera

## 8. Sistema Motivación e Incentivos

Combina **contribuciones + responsabilidad (Roles)** con **beneficios de diferentes tipos**, incluida **fluid equity**, via **algoritmo redistribución beneficios**.

### Noción Central: **Equidad (Fairness)**
- Agentes participan en juegos que consideran justos (mismos estándares para todos)
- **Alejamiento claro** de: teoría trabajo-valor (marxista) + teoría utilidad-valor (neoclásica) = **alejamiento capitalismo Y comunismo/socialismo**

### Incentivos Extrínsecos (Sensorica)
1. **Ingresos** generados por afiliados en actividades comerciales
2. **Acceso** a variedad activos: materiales, herramientas, equipos, pool talento
3. **Contexto investigación técnica/científica**: aplicar conocimientos, prototipar ideas, crear ventures, acelerar desarrollo soluciones distribuibles como productos/servicios

### Incentivos Intrínsecos (Sensorica)
1. Interés/disfrute tareas (sin presión externa)
2. Oportunidades aprendizaje contribuyendo a ventures
3. **Reconocimiento pares** → reputación formal OVN, expuesta públicamente en perfiles
4. Entorno altamente colaborativo → compartir/ayudar = gran satisfacción
5. **Sesgo comportamiento ético** (transparencia = alineación valores individuales)
6. Apertura → ventures vinculadas a resolver problemas sociales importantes
7. Movilidad dentro OVN + exposición ilimitada actividades → desarrollo skills/experiencia

### Diseño Sistema
- Mantiene **conciencia propósito, significado, importancia** de acciones cada afiliado
- Afiliados conscientes de **por qué hacen lo que hacen** y vinculación con beneficios

## 9. Proceso de Producción

- **Peer production basada en commons** (CBPP) — forma extrema, potencialmente autosostenible y regenerativa
- Agentes usan recursos en peer production = **cocreación/coproducción**
- **Vs tradicional**: producción depende intercambios (trabajo vs beneficios tangibles/dinero) → entidad asume riesgo (inversores) encierra producción
- **Cocreación**: contribuciones, riesgo compartido, producción compartida → **activos evitan mercantilización** (no se intercambian durante cocreación)
- **Trabajo NO se mercantiliza** en peer production → nadie trabaja para nadie más

### Coordinación: **Estigmergia**
- Autoorganización (estructuras roles emergentes)
- Acciones coordinadas hacia resultado compartido + facilitan acceso recursos necesarios
- Nuevo modelo producción socioeconómica: trabajo coordinado (ayuda Internet) fuera marcos institucionales tradicionales

### Régimenes Propiedad/Recursos para Acelerar Innovación
- Flujo recursos sin obstáculos dentro red → canalizado hacia centros producción
- Tendencia: mover recursos propiedad privada → **comunes, recursos compartidos, non-dominium** (plural property / shared property)
- **CBPP = síntesis**: lado commons (izquierda tradicional, comunitarismo, énfasis compartir) + lado peers (derecha tradicional, libertarianismo, énfasis libertad/autonomía individual, propiedad privada) → **aumenta libertad/autonomía individual MEDIANTE nuevos regímenes propiedad y reglas acceso/uso recursos**
- Ver: **Equilibrio individuo-comunidades**, **Peer production (P2P Foundation)**, **Producción social** (usado indistintamente)

## 15. Emprendimiento Colaborativo

### Modelos Económicos y Fuentes de Sustento (Business Models)
1. **DIY Kits** (ventas transaccionales) — vitaminas (componentes no fabricados digitalmente) para construir herramienta
2. **Componentes/partes especiales, difíciles de encontrar, custom** (ej. BackYard Brains, OpenQCM venden componentes especializados hardware abierto)
3. **Calibración/validación hardware científico** (servicio transaccional) → seguridad prosumidores construyendo propias herramientas (mediciones reproducibles, precisas, exactas)
4. **Educación/Formación** (ej. Open Source Ecology) — incluye soporte; modelo consultoría (Fjelsted et al., 2012)
5. **Servicio ecosistémico**: confianza, validación, discoverability, ayuda, lugar discutir/colaborar
6. **Ofreciendo marcos de confianza** (trust frameworks)
- Ver: **Distributed Business Model Patterns**

### Productos (Deliverables)
- Hablamos de **entregables** (algunos como bienes/servicios distribuidos via mercado)
- Transparencia = acceso info todo (procesos internos, entregables) → borra asimetría informativa
- Capitalizar estándares éticos → **prima por productos**
- Transparencia → diseño mejor ajustado a normas aceptadas
- Apertura → participación diseño → productos más valiosos
- Ver: **How to play the open game in present and future economy**

### Clientes → **Prosumidores**
- Distinción productor/consumidor difusa en economía p2p

- OVN **recompensa feedback como contribuciones** via sistema contabilidad contribuciones (vs empresas tradicionales)
- Clientes invitados a convertirse en contribuyentes → afiliados

## 16. Diseño Organizacional (Sensorica)

- OVN = red agentes colaborando objetivos compartidos (ej. diseñar hardware, difundir Creative Commons)
- Conocimiento en entregable = **compartido públicamente (transparencia)**
- **Cualquiera puede unirse para contribuir (apertura)**

### Exchange Firm (Empresa de Bolsa/Intercambio)
**Problema**: Productos requieren organización formal para intercambio mercado (LLC protege demandas producción/uso producto)
**Solución OVN**: **Exchange Firm** — organización formal construida para servir a la comunidad
**Resuelve 2 problemas adicionales**:
1. **Cheating en acuerdos comerciales**: afiliados tentados a no revelar beneficio real → organización formal sujeta a reglas estrictas, sistema justicia, profesionales = más confiable
2. **Monopolio interfaz mercado**: algunas afiliadas intentan monopolizar acceso mercado → influencia desproporcionada → Exchange Firm = **interfaz mercado única**, garantiza igualdad oportunidades acceso mercado

### Afiliados y Beneficios
- **No salario** → comparten beneficios venture (compensaciones monetarias si producto comercializado exitosamente)
- Afiliados pueden negocios propios fuera OVN
- **Benefit Redistribution Algorithm** distribuye beneficios a contribuyentes/afiliados
- **Apertura**: cualquiera puede convertirse en afiliado contribuyendo a venture
- **No todas participación = contribuciones**
- **Beneficios tangibles (monetarios) NO garantizados** incluso con contribuciones
- Ideas/procesos/productos no usados → no recompensados automáticamente
- Beneficios alternativos: aprendizaje, reputación, acceso gobernanza
- Beneficios tangibles SI: venture financiada (crowdfunding, donaciones, grants) O producto intercambiado en mercado
- En caso mercado: ingresos distribuidos cuando se vende producto
- Desarrollo producto/negocio = responsabilidad afiliados activos
- Cualquier afiliado puede tomar iniciativa propia en cualquier etapa (desarrollo → distribución)
- Afiliados activos persuaden a otros para participar/usar resultados
- En cualquier etapa value chain: decidir obtener/desarrollar desde dentro OVN o mercado; decidir vender trabajo o usar siguiente etapa
- **Solo trabajo cuyos resultados se usan se compensa** cuando ingresos regresan a value chain
- Afiliados entienden: **fracaso = parte I+D** → fracasos por buenas causas recompensados (reputación)
- **Alto riesgo fracaso = mayor peso en algoritmo redistribución beneficios**
- Redistribución ingresos cada producto = **OVN Benefit Redistribution Algorithm** — infraestructura enteramente bajo control afiliados activos
- **Contribution Accounting System = Value System + Reputation System + Role System** (interactúan)
- NRP-CAS captura: tipos contribución (Role System) + cantidad (Value System)
- Rol en OVN = **emergente** (no asignado) → Role System incita subordinación voluntaria = importante para autoorganización
- Reputación = evaluación pares (todos los demás) considerando rol → performance, comportamiento, impulso
- Reputación conectada a Value System → afecta capacidad extraer beneficios red
- Reputación incentiva buen comportamiento + enfoca atención → filtra participantes para tareas adecuadas
- Experiencia Sensorica con este sistema = **positiva**

## 18. Modelo de Crecimiento

### Nivel Red
- OVN crece por **afiliación**
- Tamaño solo limitado por **coordinación**
- Para cada venture creando exchange value → **contribution accounting system** describe cómo objetos valor fusionan en resultados
- Entregables algunas ventures = insumos otras ventures → otro contribution accounting system

### Nivel Red de Redes (Network of Networks)
- Infraestructura OVN diseñada para **estructuras fractales / Redes de Redes**
- Un OVN puede ser **contribuyente individual** en venture en otro OVN
- Término: **Super-value network**
- En teoría, concepto OVN aplicable a **economía global entera**
- **Contribution accounting a nivel venture → federado a nivel red → protocolo intercambios inter-redes y cocreación**

### 2 Modos Crecimiento Redes de Redes (observados alrededor Sensorica)
1. **Por afiliación**: redes independientes ya existentes se afilian a otras redes → ver **Open Alliance work**
2. **Por incubación y escisión (spin-off)**: personas con ideas proyecto se unen a red, hacen crecer venture, se convierten en subredes, usan recursos locales, se escinden al alcanzar masa crítica → **caso Drone y 3D Printing projects en Sensorica**
