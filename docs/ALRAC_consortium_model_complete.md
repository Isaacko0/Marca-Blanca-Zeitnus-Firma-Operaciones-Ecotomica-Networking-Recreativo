## 7. REPARTO: LEY DISTRIBUCIÓN FRACTAL DEL VALOR (LDFV)

Adoptada directamente del Sistema Alráico (aplicación económica), no negociada.

```
ω⁽ᵏ⁾ = ½ · θ_generado⁽ᵏ⁾ · (1 + ι) · φʰ⁽ᵏ⁾
φʰ⁽ᵏ⁾ = (0.95)ᵏ · (1 + αʰ⁽ᵏ⁾ / 10)
```

**En llano**: 
- Mitad del valor (θ_generado) → a quien lo generó
- Resto → reparte entre capas que participaron, ponderado por armonía (αʰ) aportada
- Incentivo **ι** → quien invierte en generar conocimiento nuevo (no solo ejecutar)

### Mecanismos de Seguridad

| Mecanismo | Fórmula | Función |
|-----------|---------|---------|
| **PPE** (Principio Potenciación Ecróxica) | γ_ind ≈ ½θ_generado | Auditoría automática: si ingreso real socio (γ_ind) ≪ ½ valor generado → explotación declarada → redistribución |
| **β_crit** | Umbral acaparamiento | Techo: si socio/capa acumula desproporcionadamente → "agujero negro económico" → redistribución automática |

**Ventaja**: Ética en la fórmula, no en la promesa. Nadie confía en buena fe de nadie.

interface LDFV {
  calculateShare(layer: Layer, metrics: LayerMetrics): bigint {
    const half = metrics.thetaGenerated / 2n
    const knowledgeBonus = 1 + metrics.iota  // ι ≥ 0
    const harmonyFactor = Math.pow(0.95, layer.index) * (1 + metrics.alphaH / 10)
    return half * knowledgeBonus * harmonyFactor
  }
  
  // PPE: γ_ind ≪ ½θ_generado → explotación → redistribución
  checkExploitation(member: Member, layer: Layer): boolean {
    return member.ligatureToInherent * 100n < layer.thetaGenerated / 2n

  // β_crit: techo anti-agujero-negro
  checkBlackHole(member: Member, totalValue: bigint): boolean {

  }
