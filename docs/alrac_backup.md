## Qué es ALRAC
ALRAC es un **modelo de negocio para federar proyectos afines sin fusionarlos**. No vende un sistema económico alternativo — vende la **capa de transición** entre el sistema existente y lo que cada comunidad decida ser.

El nombre "Alrac" proviene del sustrato relacional que el Sistema Alráico define como *"el invariante que asegura que el sistema nunca se convierta en otro instrumento de poder"*, nombrado en honor a la esposa de Amid Dabir.
