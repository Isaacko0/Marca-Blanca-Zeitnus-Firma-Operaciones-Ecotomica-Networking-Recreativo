## Resumen del Ecosistema

Este es un **ecosistema coherente de 15+ años** (2011-2026) de experimentación en **producción entre pares (peer production)**, **contabilidad de valor en redes abiertas**, y **gobernanza distribuida**. Sensorica es el **nodo central operativo** (OVN funcional desde 2011), Mikorizal/ValNet la **infraestructura de contabilidad**, y OVN el **marco teórico**.

## Open Value Network (OVN) — Marco Teórico

**Wiki**: https://wiki.p2pfoundation.net/Open_Value_Network  
**OVN Wiki**: http://ovn.world  

### Definición
> "Open Value Network (OVN) refers to a new collective form or organizational framework designed to support commons-based peer production. This type of organization is by nature and from birth transnational. An OVN is not an organization incorporated in law, but de facto."

### Tres Perspectivas
- **Social**: organización compleja, valores/normas reciprocidad/confianza emergen y se sostienen
- **Económica**: agentes colaboran abierta/transparente para producir/difundir valuables, esperando beneficios según contribución (NRP-CAS)
- **Sistema dinámico complejo**: autopoiesis, auto-organización, estructura emergente (no impuesta), Critical Path vs blueprint corporativo

### Niveles de Estructura (OVN Wiki)
| Nivel | Componentes |
|-------|-------------|
| **Proyecto** | Collaboration model, Value capture/distribution, Co-creation/exchange |
| **Open-enterprise** | Ventures, exchange firms (marketing/logística, liable por estándares éticos/calidad) |
| **Red** | Network commons, Network governance |
| **Global** | Global governance, Permanent legal structures, Network level legal, Enterprise level legal |

### Características OVN
- **Open Membership**: permissionless participation
- **Transparencia radical**: todo proceso publica info interna → accountability, copia métodos, detecta errores, externalidades visibles
- **Contribución**: work, money, goods → income sharing; contribution-based rewards (no solo tasks completadas)

### OVN vs DAO
- OVN: producción material, commons-based peer production, legal de facto association
- DAO: gobernanza on-chain, token-based, a menudo especulativo
- **Ensayo comparativo**: https://docs.google.com/document/d/17lG0vM1f9uNTwJTLOJqqpIns0QbObAaG4VhDy1dZEOE/edit

### Concepto: NRP-CAS (Network Resource Planning - Contribution Accounting System)
> "Analogous to an ERP system for value networks. Might call it NRP for Network Resource Planning."

**Funciones**:
- Planning y recording de contribuciones a proyectos/ventures
- Monthly reports: individual involvement, 5% fees generated, balance infra heavy users
- ACES/CAKE Canada emite proof of payments para accounting
- **Quien usa la herramienta = miembro de facto de la asociación** (Código Civil Quebec 2267)

## Tyranny of Structurelessness (Jo Freeman, 1970-73)

**URL**: https://www.jofreeman.com/joreen/tyranny.htm  
**Tesis central**: **No existe "structureless group"**. Cualquier grupo se estructura inevitablemente. "Structurelessness" = smokescreen para que poderosos/afortunados establezcan hegemonía no cuestionada.

### Problemas Estructura Informal
- Reglas decisiones conocidas solo por pocos
- Awareness of power limitado a quienes conocen reglas
- Quienes no conocen reglas = confusión/paranoia
- Strong/lucky establecen unquestioned hegemony

### Principios para Estructuras Democráticas (7)
1. **Delegación autoridad** para tareas específicas (responsabilidad difusa)
2. **Rotación tareas** (evita propiedad informal, permite aprendizaje)
3. **Asignación tareas criterios racionales** (habilidad, interés, responsabilidad — no likability)
4. **Difusión información** frecuente a todos (information = power)
5. **Acceso igual recursos** necesarios (skills, info, herramientas)
6. **Accountability** a quien delegó autoridad
7. **Acceso igual proceso decisión**

## Open Organizations Framework (2005-2014)

**Archive**: https://web.archive.org/web/20140907082133/http://open-organizations.org.uk:80/view/Main/IntroToOpenOrg  
**Procesos Regulares (4+1 extraordinario)**:
1. **Decision-making**: rough consensus within working groups (ongoing, no interrumpe tasks)
2. **Accountability**: delegación + reporte + recall
3. **Transparency**: información accessible, procesos visibles
4. **Coordinating**: Inter-Working Groups (IWG) processes
5. **Excluding**: proceso extraordinario para conducta dañina

**8 Reglas Funcionales**:
1. Charter (acuerdo explícito)
2. Open participation (permissionless entry)
3. Self-management (autonomía operacional)
4. Best practices (learning compartido)
5. Respect for skill (mérito sobre estatus)
6. Public ownership of knowledge (commons)
7. Diversity (cognitiva, demográfica, experiencial)
8. Affirmative terms (lenguaje constructivo)

## VSM (Viable System Model) — Stafford Beer

**Aplicado en**: Gaian Democracies, Open Co-ops inspiration  
**5 Subsistemas para Viabilidad** (adaptación autónoma a entorno cambiante):
| Sistema | Función | Analogía |
|---------|---------|----------|
| **1. Operational Units** | Interacting units doing the work | Órganos en cuerpo, jugadores en equipo |
| **2. Stability/Conflict Resolution** | Coordina unidades operativas | Sistema nervioso autonómico |
| **3. Internal Eye (Optimization)** | Optimiza/sinergias entre unidades | Homeostasis, gestión recursos internos |
| **4. External Eye (Strategy)** | Adapta a entorno cambiante | Percepción ambiental, planning estratégico |
| **5. Policy/Identity** | Autoridad última, desarrolla policy | Identidad organizacional, valores supremos |

**Principio**: Cada subsistema viable contiene los 5 recursivamente (holones).
