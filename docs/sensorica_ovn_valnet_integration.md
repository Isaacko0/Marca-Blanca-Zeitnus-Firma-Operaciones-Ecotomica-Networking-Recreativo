## Isomorfismo Detallado Leyes I/II/III + CaaS (Por Módulo)

### `ovnGovernance` — Gobernanza Red Distribuida

**Ley I**: Open membership = no dañar base social (permissionless). Network commons protection = constraints solo para proteger shared resources. Critical Path = initial conditions para viabilidad (no blueprint impuesto).

**Ley II**: Network governance = CDS distribuido (stakeholders = control centers independientes). VSM System 3 (Internal Eye) = optimización sinergias = AUT colectivo. Exchange firms = interfaz mercado ética = AUT económico.

**Ley III**: Radical transparency = todo proceso publica info (accountability, copy methods, detect errors). Radical openness = constraints explícitos (solo protegen commons). Tyranny principles = anti-hegemonía informal (delegación, rotación, criterios racionales, difusión info, acceso igual).

**CaaS**: Network-level CaaS = commons access por contribución. Project-level = venture participation por contribución. Global governance = policy authority por contribución sostenida.

### `valNetAccounting` — Contabilidad Valor Distribuida

**Ley I**: Resource tracking = base material accounting (tangible/intangible). Economic events append-only = no dañar registro histórico. Agent-centric = soberanía datos agente.

**Ley II**: Contribution accounting = work/money/goods → income sharing (AUT via contribución real). 5% fee pool = CDS financiero redistributivo. NRP vs ERP = planning para redes no corporaciones (soberanía red).

**Ley III**: ValueFlows standard vocab = transparencia semántica interoperable. VAS reports mensuales = contabilidad verificable. Commitment/Intent/Action/Observation = trail completo auditable. hREA p2p = no central control = lucidez arquitectónica.

**CaaS**: `caas-credits` primitive = earning (contribute) / spending (access). `identity-rao` = agent attribution. `value-dual` = ZNU/USD/BTC priceParity para economic events. `consensus-gossip` = p2p sync (hREA pattern).

### `sensoricaOVN` — Nodo Operativo Real

**Ley I**: Lab commons = base material compartida (espacio, equipamiento, calendario). Stigmergic coord = no coerción (signaling via environment). Open ventures = barrier entry baja.

**Ley II**: Peer production = AUT via producción entre pares (80% cost savings). Venture model = CDS via colaboración many-to-many. Exchange firms = mercado interface sin perder soberanía.

**Ley III**: Shared calendar/messaging = transparencia coordinación. NRP-CAS integration = contribución tracked. Gigs = contribución explícita (grant writing, fabrication).

**CaaS**: Lab access = CaaS via contribución (heavy users pay if 5% fees < $50). Venture participation = earning CaaS credits. Exchange firm services = spending CaaS credits.

### `mikorizalProtocol` — Protocolo Simbiótico Base

**Ley I**: Mutual benefit rule = no degradar sistema (regla universal). Input-process-output = flujos que respetan base material (output = input otro).

**Ley II**: Internetworking = CDS escalado (redes cooperativas > individuos competitivos). Devonian metaphor = colonización requiere simbiontes ya presentes (infraestructura previa).

**Ley III**: Conversations for action = agreement sobre acciones (no command). Cooperative creation = transparencia intenciones. Mutual coordination = lucidez vs command-control.

**CaaS**: Resource flows = CaaS primitives (input/output = earning/spending). Economic ecosystems = CaaS networks. Mycorrhizal network = protocolo handshake generativo (mutualismo metabólico).
